# EXP-DP-CLIP-HEALTH-FUSION-SCREEN-20260726

## Decision and hypothesis

- Decision: determine whether the accepted DP workload should fuse its
  fail-closed gradient-health check with the mandatory global gradient clip.
- A: current every-step `GradientHealthCallback` norm plus the existing
  foreach global clip.
- B: disable the duplicate callback norm and make the existing foreach clip
  fail closed with `error_if_nonfinite=true`.
- Falsifiable hypothesis: B improves 1,000-step steady throughput by at least
  0.5% while preserving finite-gradient clipping and immediate NaN failure.
- Null: the safety canary fails, improvement is below 0.5%, or any
  safety/control gate fails.

For finite gradients both arms use the same `clip_grad_norm_` norm algorithm,
threshold 1.0, and foreach implementation. B removes one redundant full
gradient traversal and host sync; it changes observability detail, not the
optimizer update.

## Frozen stages

1. C: one target-GPU canary creates a finite `[3, 4]` gradient, proves it is
   clipped to norm at most 1.00001, then injects NaN and requires a
   `RuntimeError` before an optimizer step.
2. Only if C passes, run A-B: exact 1,000-step / 96,000-sample forks of cache
   source `20260726-2127_dt-dp-async-validation-cache-source-20260726_b2ed`.
3. A and B use independent verified private clones of
   `outputs/.cache/full-default-batch96-channels-off-async-validation-source`
   and one content-addressed three-file artifact.

Primary estimand: `(B throughput / A throughput - 1) * 100`.

Fixed controls: batch 96, compile full/default, `compile_dynamic=null`,
`compile_fullgraph=false`, BF16, native contiguous layout, cuDNN benchmark,
batch validation interval 1, action-MSE interval 500, tensor LR off, fused
AdamW, gradient clip norm 1.0, seed 42, LIBERO-10 fingerprint
`8b15281b1f0efd56`, `psibot-ds` GPU 0, and identical
snapshot/environment/data/disk/VRAM/host-memory/cache contracts.

## Gates

1. C passes both finite clipping and fail-closed NaN checks, and its child
   process writes hook evidence;
2. A and B exit 0 and complete 1,000 optimizer steps / 96,000 samples;
3. B steady throughput is at least 0.5% above A;
4. resolved configs differ only at `callbacks.gradient_health`; arm and hook
   sidecars prove the intended implementations;
5. both clean runs report zero NaN, Inf, uncontained gradient explosion,
   CUDA, telemetry, and thermal anomalies; B's loss/throughput outputs remain
   finite;
6. peak VRAM is below 23,500 MiB and temperature below 85 C;
7. `dt compare` matches snapshot, payload, artifact, environment, node, GPU,
   boot, path, disk, and resource guards;
8. both cache receipts identify the same immutable source; FIFO handoff is
   below 12 seconds and both lightweight pulls succeed.

## Budget and stopping

- C: at most 0.05 GPU-hours; A/B: at most 0.25 GPU-hours each.
- Total ceiling: 0.55 GPU-hours.
- Stop immediately if C fails. Otherwise stop after A-B, recovery, and one
  registered comparison.
- A positive screen selects a source implementation and separately frozen
  replicated confirmation; it does not promote the experiment-only hook.
- A negative result retains the current callback and closes the candidate.
- No retry, search, reorder, replicate, or threshold relaxation is permitted.

## Outcome

GPU canary
`20260726-2206_dt-dp-clip-health-gpu-canary-20260726_d2ce` finished in
1.717470 seconds with exit 1. The process-start hook was imported and wrote
`clip-health-hook-applied.json`, but the frozen child probe referenced
`os.environ` without importing `os`. It raised `NameError` before emitting
the required finite-clip and NaN-fail-closed result object.

The job used the intended exact snapshot and artifact manifest, reached only
471 MiB peak VRAM and 42 C, reported no GPU telemetry error, and recovered
all lightweight evidence. These facts prove bounded dispatch and hook entry,
but they do not satisfy the two-part safety gate.

## Decision

Per the frozen stopping rule, do not repair or rerun the canary and do not
submit A-B. Retain the current every-step `GradientHealthCallback` plus global
clip. This experiment makes no performance claim about the fusion candidate.
Machine-readable closure is in
`results/dp-clip-health-fusion-screen-20260726/experiment-summary.json`.
