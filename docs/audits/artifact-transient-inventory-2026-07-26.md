# Artifact transient-input visibility — 2026-07-26

## Failure contract

During the real DP compile-dynamic screen, local runner validation created
`__pycache__/run.cpython-310.pyc` beside the intended `run.py`. The public
`dt batch --artifact outputs/dt-dp-compile-dynamic-static-screen-20260726`
call correctly treated the directory as an exact artifact, but gave no
specific warning that the generated bytecode had joined the frozen input.
The resulting artifact contained two files and 5,671 bytes instead of the
operator-intended one source file.

Artifact directories must remain exact inputs: silently excluding ignored
files would make the manifest describe something different from the selected
source. The missing behavior was bounded visibility before remote access and
machine-readable evidence in the sync receipt.

## Root cause and repair

Project code snapshots use `SNAPSHOT_EXCLUDES`, including `__pycache__/` and
`*.pyc`. Explicit artifacts intentionally bypass those filters and are hashed
by `_artifact_identity()` before exact rsync. No preflight classified common
transient paths.

`sync_artifacts()` now:

- detects Python bytecode, `__pycache__`, common pytest/mypy/Ruff/Hypothesis
  caches, notebook checkpoints, coverage files, and `.DS_Store`;
- emits an actionable warning before the remote artifact lock, probe, or
  transfer;
- returns a bounded `transient_files` object with exact count, up to 20 paths,
  and an explicit truncation flag;
- continues hashing and syncing every selected byte exactly, so existing
  artifact and manifest semantics remain unchanged.

README and agent guidance state this exact-input boundary and recommend
removing transient files or selecting individual artifacts when the files are
unintended.

## Evidence

The focused regression first failed with missing `transient_files`, then
passed after the repair. The complete affected sync/batch suites passed
67/67.

A real public read-only replay against `psibot-ds` used the same source
directory:

```bash
dt sync psibot-ds -p omnistack \
  --artifact outputs/dt-dp-compile-dynamic-static-screen-20260726 \
  --plan --json
```

Before any remote write, stderr named
`outputs/dt-dp-compile-dynamic-static-screen-20260726/__pycache__/run.cpython-310.pyc`.
The JSON receipt reported `count=1`, the exact path, and
`paths_truncated=false`. The manifest remained
`e11569558f02ffd4886ef1ebdb203194fbd9718bee1837c58776fd679d49a6ce`,
the source remained 5,671 bytes, and the plan reported zero changed files.
This proves that visibility was added without rewriting the selected artifact
or its identity.

Ruff lint and format checks pass for the changed Python and regression-test
files. Full repository verification is recorded in the core workflow audit
after the running DP screen completes.
